# Travel Cost Tracker PWA

A Progressive Web App to track travel costs and sync to Google Sheets.

## Features
- 🎯 Quick cost entry with preset buttons
- 💱 Multi-currency support (GBP/EUR)
- 🚆 Track transport modes (Flight, Train, Taxi, Bus)
- 📱 Works offline with automatic sync
- 📊 Syncs to Google Sheets automatically

## Setup
1. Open the app
2. Enter your Google Apps Script deployment URL
3. Start tracking costs!

## Technologies
- Vanilla JavaScript
- Service Workers for offline support
- IndexedDB for offline queue
- Google Apps Script backend
